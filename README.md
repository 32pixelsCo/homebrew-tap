# 32pixels Homebrew Tap

Homebrew formulae and casks for [32pixels](https://github.com/32pixelsCo) products.

```bash
brew tap 32pixelsco/tap
brew install shaft          # the Shaft game (CLI-launched binary)
# brew install --cask shaft # notarized Shaft.app (once released)
```

Formulae are updated automatically by each product's release workflow.
